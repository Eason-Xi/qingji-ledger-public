# 三分钟上手

## 先体验

点击顶部“创建示例账本”，会单独建立一个带有“虚构数据”标识的账本，包含示例工资、房租、消费、换汇和银证转账。切回“个人账本”开始记录真实数据。

## 建立自己的账户

在“我的账本 → 账户管理”编辑默认账户或新增账户。人民币期初与港币期初单独填写；港币折算汇率只影响人民币净资产估值，不改变原币数量。香港银行与内地银行都可选择人民币或港币转账。

## 日常记账

“一句话记账”输入多笔内容，如“午餐32；咖啡18；打车25”。规则识别后会追加到待审核列表，可多次输入；核对完成后统一审核入账。也可以用“记一笔”填写表单。

语音输入需浏览器支持并由你主动允许麦克风。无需语音也可以完整使用。

## 转账和港股

在“记一笔 → 内部转账”选择转出和转入账户，可分别选择扣款币种和到账币种。跨币种填写两边实际金额。

新建港股证券账户后，从普通银行账户通过内部转账入金。股票买卖只使用证券账户中的现金，不重复扣银行余额。现价由你手动更新，系统不进行实际买卖。

## 看统计

“统计报表”提供“日常收支”和“资金流向”。前者统计消费、退款、净支出、收入与结余；转账不算消费。后者按账户及人民币/港币分别列出资金变化，银行与证券之间的转账也在其中。

## 备份和换设备

进入“我的账本 → 迁移与备份”，点击“下载当前账本备份”。每个账本分别备份。在新浏览器或自己部署的网站打开同一菜单，选择“恢复备份”。

CSV / Excel 用于查看和交换日常流水；完整迁移请使用 JSON，因为它包含预算、账户、港股和数字资产资料。最近20个版本保存在当前浏览器，不能替代下载备份。
